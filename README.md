# SWK Studios Homebrew tap

Homebrew formulas for SWK Studios tools.

## Install

```sh
brew install swkstudios/tap/<formula>
```

Or add the tap once and install by name:

```sh
brew tap swkstudios/tap
brew install <formula>
```

## Formulas

Formulas live in [`Formula/`](Formula/). Each tool's release process updates its formula's version and checksum.
